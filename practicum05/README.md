Практична робота 5. Робота з AJAX та JSON.

Переробив взаємодію з базою даних на асинхронні запити за допомогою fetch. Створив окремі PHP-ендпоінти (api_list, api_add, api_buy), які не генерують HTML, а віддають і приймають дані суто у форматі JSON.

На фронтенді реалізував живий пошук по локації — таблиця фільтрується при кожному натисканні клавіші без перезавантаження сторінки. Також додавання нових подій і зменшення лічильника вільних місць (при покупці квитка) тепер відбувається асинхронно, і DOM оновлюється динамічно.
