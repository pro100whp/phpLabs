# Практична робота №1 з PHP

**Варіант 15:** Система бронювання квитків.

## Що зроблено в коді
* Створив масив подій (назва, дата, ціна, залишок місць)
* Написав типізовану функцію для форматування інформації про подію
* Додав перевірку: якщо `seatsLeft = 0`, виводиться червона мітка «Квитків немає»
* Написав цикл, який рахує агрегатний показник — сумарний потенційний дохід з усіх квитків

## Як запускав
Робив через XAMPP. Просто закинув папку з проєктом у `C:\xampp\htdocs\`, запустив локальний сервер (Apache) і відкривав у браузері
