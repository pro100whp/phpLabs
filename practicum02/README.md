# Практична робота 2 з PHP
Варіант 15 (Система бронювання квитків)

Що тут зроблено:

Написав HTML-форму для бронювання квитків. Користувач вводить назву події, кількість місць (від 1 до 10) та свою пошту. 

Додав два рівні валідації. Спочатку на стороні браузера (HTML5 та JavaScript) перевіряється формат імейлу та ліміт квитків. Якщо все нормально, форма відправляється на сервер, де PHP ще раз жорстко перевіряє ці самі дані через масив $_POST, щоб нічого зайвого не пройшло.

Також тут є захист від базових XSS атак — усі дані, які повертаються у форму, проходять через функцію htmlspecialchars.

Ну і додатково прикрутив збереження чернетки форми через localStorage. Якщо юзер почав щось вводити, але випадково оновив сторінку, JavaScript дістає збережені дані і сам заповнює поля, щоб не довелося писати все заново.
