Практична робота 12. Анімація, Canvas та інтерактивні ігрові елементи.
Варіант 15 - Каталог рецептів напоїв.

Обрана технологія: CSS-анімація.

Що реалізовано:
Додано інтерактивний елемент — анімацію «наливання» напою при відкритті картки рецепта.
Для цього використано CSS-властивість `transform: scaleY()` у комбінації з `transform-origin: bottom`. 

Плавність наливання забезпечується властивістю `transition: transform 1.2s ease-in-out`. 
Анімація спрацьовує при кліку на картку напою (через перемикання класу `active` за допомогою JavaScript), що повністю відповідає вимогам інтерактивності та візуалізації даних обраного домену.
