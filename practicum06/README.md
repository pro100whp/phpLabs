Практична робота 6. Розробка власного API.

Реалізовано REST API з єдиною точкою входу (файл api.php). Налаштовано маршрутизацію на основі HTTP-методів та URL-параметрів (resource, id, action).

Ресурс: events

Підтримувані маршрути:
- GET /api.php?resource=events — повертає весь список подій. (HTTP 200)
- GET /api.php?resource=events&id={id} — повертає дані конкретної події, або HTTP 404, якщо не знайдено.
- POST /api.php?resource=events — створення нової події. Повертає HTTP 201 та ID нового запису. Перевіряє наявність усіх обов'язкових полів (якщо ні — HTTP 400).
- POST /api.php?resource=events&action=buy — доменна дія покупки квитка. Зменшує кількість доступних місць на 1, якщо вони ще є.

Усі відповіді API використовують уніфікований формат JSON (структура {"success": true|false, "data": ... | "error": ...}).
