Практична робота 4. Система бронювання (БД).

Реалізовано взаємодію з базою даних MySQL за допомогою розширення PDO.
Створено таблицю events для зберігання подій.
Налаштовано обробку помилок бази даних (ERRMODE_EXCEPTION).

Виконано всі базові CRUD-операції:
- SELECT: виведення всіх подій та окремий список подій без вільних місць.
- INSERT: додавання нових записів через форму.
- UPDATE: редагування кількості вільних місць для конкретної події.
- DELETE: видалення запису з підтвердженням через JavaScript.

Усі SQL-запити використовують prepared statements (підготовлені запити) для захисту від SQL-ін'єкцій.
