Практична робота 3 з PHP. Варіант 15 - Система бронювання.

В цій лабі розбирався з основами ООП. Зробив базовий клас Event для звичайних подій та клас TicketedEvent, який його наслідує і додає специфічні властивості типу ціни та кількості місць. Також написав клас-менеджер TicketOffice для зберігання масиву подій і методів пошуку по локації та фільтрації тих подій, де закінчились місця.

Весь код розбив по файлах. Класи лежать у папці classes, а допоміжні функції для форматування дати та розрахунку доходу — в папці lib. У головному файлі index.php все підключається через require_once.
