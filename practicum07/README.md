Практична робота 7. Оптимізація та навантажувальне тестування.

В цій роботі я провів оптимізацію скрипта api.php для роботи під навантаженням. Спочатку зробив заміри без оптимізацій: час виконання запиту становив близько 32 мс, а Apache Bench (ab -n 200 -c 20) показав 140 Requests per second.

Знайшов вузьке місце: N+1 запит при підрахунку кількості подій в одній локації (venue). Переписав це на один агрегатний запит із використанням LEFT JOIN та GROUP BY замість виконання окремого запиту в циклі.

Створив індекс у базі даних на стовпець venue, щоб пришвидшити пошук та групування результатів.

Додав файлове кешування з TTL 60 секунд для виклику action=soldout, оскільки список розпроданих подій змінюється не так часто, а сам запит може створювати зайве навантаження. При купівлі останнього квитка кеш інвалідується (видаляється).

Після всіх оптимізацій нові заміри показали приріст продуктивності: час виконання впав до 8 мс, а пропускна здатність зросла до 420 Requests per second.
